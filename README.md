# RPG гра

Браузерна RPG з автоматичними боями. Одна версія для Windows, Android, планшетів і телефонів.

## Як грати

**Онлайн / як застосунок (рекомендовано)**
1. Відкрити адресу гри на GitHub Pages.
2. ПК (Chrome / Edge): іконка «Встановити» в адресному рядку → гра з'явиться як окремий застосунок з ярликом.
3. Android (Chrome): меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
4. Після першого запуску працює без інтернету.

**Локально на ПК** — подвійний клік по `index.html`.

## Сейви

Зберігаються в браузері (IndexedDB) окремо на кожному пристрої.
Щоб перенести прогрес — «Експорт» у JSON-файл на одному пристрої та «Імпорт» на іншому.
